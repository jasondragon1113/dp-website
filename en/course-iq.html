What kids learn in VEX IQ

VEX IQ is a robotics kit with a plastic structure, a brain, and a range of sensors. Kids learn building, coding, and teamwork all in one course.

Besides Scratch-style visual coding, kids can also program the robot in C++. Each unit has its own goal, so kids pick up more STEAM knowledge along the way.

What they learn

  • Building mechanisms
  • Using sensors
  • Visual and C++ coding
  • Autonomous programs
  • Teamwork

Highlights

What class looks like

01

Visual coding to C++

Start with visual coding, then move on to C++.

02

Project-based classes

Each unit has one goal, and kids learn STEAM on the VEX IQ platform. After the course, they can join VEX IQ competitions.

03

A clear path to V5

After VEX IQ, kids can move on to VEX V5, with its metal structure, and head toward more advanced robots.

How classes work

Every class works like this

  • 10 kids max per class
  • A kit for every child
  • Make-up classes
  • Parts cleaned regularly

What age can kids start?

From age 3 with ESM, then SPM at 6 and VEX GO at 7 — and it keeps going all the way through high school.

How big are the classes?

Small classes — 10 kids max.

Do we need to buy a kit?

No. Every child gets their own kit in class — no sharing needed.

Can we make up a missed class?

Yes. Just let us know and we'll set up a make-up class.

What if my child wants to compete?

Yes — we have Competition Teams for VEX, FIRST and WRO. VEX IQ / V5 teams start at the end of June each year.See Competition Team
