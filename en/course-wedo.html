What kids learn in WeDo 2.0

Each class brings in a science question or mission from everyday life. Kids use the WeDo 2.0 kit and software to find the answer hands-on, which sparks an interest in exploring and learning.

Code comes in blocks you drag and snap together, so it's easy to pick up. Kids can also use Scratch to bring their LEGO models to life.

What they learn

  • Visual block coding
  • Motors and sensors
  • Science in daily life
  • Teamwork and sharing

Highlights

What class looks like

01

Visual block coding

Code is made of blocks, so it's easy to get started. Kids can also use Scratch.

02

Project-based classes

Each class starts from a problem kids might run into in real life. They see how the parts work together, share their process with classmates, and practice teamwork and communication.

How classes work

Every class works like this

  • 10 kids max per class
  • A kit for every child
  • Make-up classes
  • Parts cleaned regularly

What age can kids start?

From age 3 with ESM, then SPM at 6 and VEX GO at 7 — and it keeps going all the way through high school.

How big are the classes?

Small classes — 10 kids max.

Do we need to buy a kit?

No. Every child gets their own kit in class — no sharing needed.

Can we make up a missed class?

Yes. Just let us know and we'll set up a make-up class.

What if my child wants to compete?

Yes — we have Competition Teams for VEX, FIRST and WRO. VEX IQ / V5 teams start at the end of June each year.See Competition Team
